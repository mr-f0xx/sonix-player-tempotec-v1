What I would change after approval

  1. Add a third choice in the existing Theme card on Appearance: Dark, Light, Tokyo Night. Selection applies immediately and persists.
  2. Add a Tokyo Night palette to the shared theme manager while leaving today's Dark/Light colors and settings behavior intact; read older saved Dark/Light preferences as before.
  3. Recolor the existing function-matched icons—music, playback, wireless, settings, EQ—with Tokyo Night foreground and semantic accent colors. No AI-generated icon artwork.
  4. Validate the V1 profile at 240 × 320, including the wrapped/compact Theme choices and memory/performance-sensitive drawing.

V1-friendly approach: the prototype reuses the repository’s existing glyphs. The production palette would be a few static colors; no new fonts, large icon packs, full-screen blur buffers, or animated glow. A subtle active-icon halo can be evaluated separately against the device’s draw cost.
